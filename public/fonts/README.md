# 本地字体

- Noto Sans SC variable：中文与界面正文，100–900字重。原始文件 https://github.com/google/fonts/tree/main/ofl/notosanssc ，随附 NotoSansSC-OFL.txt。
- JetBrains Mono variable：分支名与代码内容，100–800字重。原始文件 https://github.com/JetBrains/JetBrainsMono ，随附 JetBrainsMono-OFL.txt。

均随桌面应用打包，运行时从本地加载，不连接字体 CDN。保留完整中文字符覆盖，不按当前页面文案裁剪，支持用户项目名称与备注。
